| HTTP Method | Endpoint | Description |
| ----------- | -------- | ----------- |
| GET         | /languages | retrieves all languages |
| GET         | /languages/{id} | retrieves one language |
| POST        | /languages | creates a language resource |
| PUT         | /languages/{id} | replaces a language resource |
| PATCH       | /languages/{id} | updates a specific language resource |
| DELETE      | /languages/{id} | deletes a specific language resource |
