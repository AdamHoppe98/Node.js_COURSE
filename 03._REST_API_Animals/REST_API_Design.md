GET /animals
GET /animals/{id}

| HTTP Method | Endpoint | Description |
| ----------- | -------- | ----------- |
| GET         | /animals | retrieves all Animals |
| GET         | /animals/{id} | retrieves one Animal |
| POST        | /animals | creates a animal resource |
| PUT         | /animals/{id} | replaces a animal resource |
| PATCH       | /animals/{id} | updates a specific animal resource |
| DELETE      | /animals/{id} | deletes a specific animal resource |
